# RentCar — демо сервиса аренды авто (Томск)

Кликабельный прототип для показа владельцу. Работает **без сервера**: все данные хранятся в браузере (localStorage). В нём не используются CDN, Google Fonts или аналитика, поэтому страница грузится быстро и после первого открытия работает офлайн благодаря service worker.

## Интерфейс

При первом открытии за сессию показывается заставка: машина влетает справа и резко тормозит, из-под колёс летит песок. Её можно пропустить кликом или клавишей Esc, повторить — кнопкой в подвале. При включённом в системе «уменьшении движения» заставка не показывается.

Интерфейс построен как экран автомобиля: боковое меню-рейка, строка статуса (время в Томске, связь, адрес, телефон) и стеклянные плитки-виджеты. Есть три режима экрана: **Авто** (по настройке системы), **День** и **Ночь**. Переключатель находится внизу рейки, на телефоне — в строке статуса.

## Что внутри

**Для клиента**
- Главная-дашборд:
  - сцена с машиной и переключателем классов в виде режимов езды (Эконом / Комфорт / Премиум);
  - помощник с быстрыми действиями и ответами по правилам проката;
  - виджеты «Место выдачи» (навигатор), «Мои даты», «Оплата», «Рекомендуем» и блок «под такси».
- Автопарк из 15 машин. У части машин пока нет фото: они показаны векторным силуэтом с подписью «иллюстрация», фото добавит владелец.
- Каталог с фильтрами: даты (показывает только свободные), класс, коробка, топливо, цена, «под такси», сортировка.
- Карточка машины: характеристики, тарифы по сроку, календарь занятости на 4 недели, расчёт цены.
- Бронирование в 4 шага: даты и опции → данные водителя (проверка возраста и стажа) → фото паспорта и прав → автоматически собранный договор и подпись пальцем.
- Условия аренды, цены и FAQ, контакты с картой, кнопки звонка и мессенджеров.
- Онлайн-оплата при бронировании или позже из «Моих броней»: СБП или карта на странице банка, залог только замораживается. В демо платёж имитируется, деньги не списываются.
- Автоматическая страховка: при подтверждении брони на клиента, машину и даты выписывается сертификат к открытому полису владельца.
- «Мои брони»: статус заявки и оплаты, договор, страховой сертификат.

**Для владельца** (`#admin`, демо-PIN `2002`)
- Сводка: новые заявки, свободные машины, выручка за 30 дней, загрузка парка на 2 недели, выдачи и возвраты на сегодня.
- Заявки: данные клиента, статус оплаты, страховой сертификат, проверка возраста и стажа, фото документов, договор, кнопки «Подтвердить / Отклонить / Выдана / Вернули», предупреждение о пересечении дат.
- Календарь (диаграмма Ганта) по всем машинам.
- Автопарк: статус (в работе, на ТО, скрыта), цена с автоматическим пересчётом скидок за срок, добавление машины с фото и удаление.

Бронь, оформленная на сайте, сразу появляется в панели владельца, а его решение видно клиенту в «Моих бронях». Кнопка «Сбросить демо» в подвале возвращает исходные данные.

## Запуск

Сборка не нужна, это обычная статика.

```bash
python3 -m http.server 8080   # затем открыть http://localhost:8080
```

### GitHub Pages
Деплой автоматический: при каждом пуше в `main` workflow `.github/workflows/pages.yml` публикует сайт (Settings → Pages → Source: GitHub Actions).

Адрес: https://bug1vuge.github.io/rent-car/

```

js/store.js           «база» в localStorage, расчёт цены, проверка занятости
js/assistant.js       помощник на главной (сценарии по правилам проката)

js/admin.js           панель владельца
sw.js                 офлайн-кэш (при изменениях увеличить VERSION)
fonts/, img/          шрифт Onest (OFL), фото машин и вырезанные силуэты
```

## Что нужно уточнить у владельца

Все цены, залоги, характеристики, правила, часы работы и номера машин — заглушки. Модели Changan Alsvin и Hongqi H5 определены по фото из сторис, их нужно проверить. Также нужны реквизиты арендодателя для договора и ссылки на сообщества в VK и Max (`PM.BIZ` в `js/data.js`).

## Путь к полной версии

- Бэкенд и БД (например Node.js или Python + PostgreSQL) на хостинге в РФ, так как это требование 152-ФЗ для паспортных данных. Модуль `store.js` заменяется на запросы к API.
- Хранение документов в закрытом S3-хранилище, вход владельца по номеру и коду.
- Уведомления владельцу и клиенту через ботов Max и VK.
- Договор в PDF, при желании — подписание ПЭП по коду из SMS.
- Онлайн-оплата через платёжный сервис (ЮKassa, Т-Банк, СБП-эквайринг): сейчас имитируется в js/payments.js.
- Страховка: данные открытого полиса (`RC.BIZ.insurance` в js/data.js) и, если страховая даёт API, автоматическая отправка сертификата в страховую.
- **Ограничения мобильного интернета.** Сам сайт не попадёт в «белые списки», поэтому бронирование нужно продублировать ботом в Max и VK. Бот работает через серверы мессенджеров, а они в белом списке. Сайт и бот используют один и тот же API.
